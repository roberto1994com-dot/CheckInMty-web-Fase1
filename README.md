# AWS Cloud Web Deployment Lab

##  Project Overview

This project demonstrates the deployment of a web application on Amazon Web Services (AWS) using DevOps principles and cloud technologies.

The objective was to deploy a functional website while applying infrastructure management, Linux server administration, cloud security fundamentals, and deployment automation. Throughout the project, industry-standard tools such as Amazon EC2, GitHub, GitHub Actions, Apache HTTP Server, and Linux were used to simulate a real-world deployment workflow.


---

##  Objectives

- Deploy a web application on Amazon Web Services (AWS).
- Configure and manage a Linux-based EC2 instance.
- Implement secure remote access using SSH Key Pairs.
- Configure Security Groups and networking components.
- Automate deployment using GitHub Actions.
- Apply fundamental DevOps and cloud security practices.
